# M21 — Polish and Ottoman civs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two playable civs, Polish and Ottoman. Each gets three age styles, a Wonder, walls, a unit look, a unique unit, a civ bonus and a landmark. The match setup offers 10 civs.

**Architecture:** This follows the M5 per-civ path (CLAUDE.md §9 M5 checklist, items 1–6). Each civ lives in its own folders (`src/iso/art/{architecture,walls,units}/<civ>/`) and adds one row to each art registry. Every game effect reuses an existing kind: `villagerSpeed`, `trainSpeed`, `mint` and `sauna`. The unique units follow the M8 replacement rule.

**Tech Stack:** TypeScript strict, Phaser 3 (procedural canvas art), Vitest, zod saves.

**Spec:** `CLAUDE.md` §9 "M21 — Két új nép: lengyel és oszmán" (Hungarian). §9 M5 has the add-a-civ checklist. M8 has the unique-unit rule and M17 the landmarks.

## Global Constraints

- **UI text** goes only in `src/i18n/hu.ts`.
- **Stat numbers** go only in `src/config/balance.ts`.
- **Civ ids** may appear only in the files that `src/config/civSurface.test.ts` allows.
- **Existing pins:** Hungarian, English and every M5 civ keep their pinned art hashes unchanged, and so do the shared painters.
- **Game state of existing civs:** their skirmish games stay bit-identical given the same civ line-up. Campaign missions stay bit-identical, because their mixed draw uses `CLASSIC_CIVS` (the 8 old civs).
- **Saves:** `schemaVersion` 15, with an identity migration `v14ToV15` and a real v14 fixture. Every old save still loads (`allVersions.test.ts`).
- **Budget:** land textures ≤ 256 MB, sea maps ≤ 400 MB, measured on the worst 6-civ case with `scripts/perf/texmem.mjs`. Each civ adds at most about 1 s of load time. The bundle stays under 2 MB gzip.
- **Ports:** the dev server runs only on port 5196. Never touch 5173.
- **Git:** never use `git add -A` (`node_modules` is an untracked symlink), and never use a bare `git stash`. Use conventional commits.
- **Subagents** never dispatch further subagents.

## Review Focus

1. **Silhouette distinctness at zoom 1.0:**
   - Polish age 2 against German `backstein`: no stepped gables, but an uneven twin tower.
   - Polish age 1 against Russian `rus_gord` and Finnish `finnic`: long thatched row houses.
   - Ottoman age 3 against Russian onions: lead domes, not onions, plus a pencil minaret.
   - Ottoman age 1 against Hungarian `roman`: banded brick and stone walls with low domes.
2. **Unit cue rule and team readability (M5):** every age has one distinctive cue. The team-mask coverage is at least 0.8 × the Hungarian coverage.
3. **Old pins:** no existing pin moves. A kit extracted into `kits/` keeps the old civ's hashes.
4. **Campaign determinism:** every mission's `matchCivs` result equals its pre-M21 value.
5. **Loading an M20 mixed-civ save:** the players' civs come from the save and are painted, not re-drawn from the larger pool.
