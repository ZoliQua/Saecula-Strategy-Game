# M22 Art Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Polish and Ottoman nations their own painters for every military/workshop building (barracks, archery range, stable, blacksmith) in every age, and age-3 bastions (plus the age-2 Rumeli towers) that read as their own at play zoom.

**Architecture:** Procedural canvas painters (`src/iso/art`). Each civ age-style's art set (`ottoman/ottoman.ts`, `polish/polish.ts`) spreads a shared family (`romanArt` / `medievalArt` / `baroqueArt`) and overrides some slots; this plan adds overrides for the missing slots, built from the civ's existing parts (`ottomanParts.ts`, `biskupinParts.ts`, `krakowParts.ts`, kits `leadDome`, `minaret`, `lowHip`, …). Walls change only in the civ wall folders; `walls/kits/starFort.ts` may gain an optional, default-off switch.

**Tech Stack:** TypeScript strict, Vitest, procedural canvas (`IsoPainter`).

**Spec:** `CLAUDE.md` §9 M22 (commit a4f5b6e).

## Global Constraints

- Graphics only: no change to gameplay, `balance.ts`, saves (`schemaVersion` 15), AI, `hu.ts`.
- Every replacement painter keeps the **same `size` and the same `maxHeight`** as the shared painter it replaces (read it from `roman.ts` / `medieval.ts` / `baroque.ts`), so texture memory does not grow.
- **All other civs' pins stay byte-identical** (`src/iso/art/**/**Pinned.test.ts` for hungarian, english, german, french, spanish, italian, russian, finnish). Shared family/kit files may only gain optional, default-off switches.
- Polish/Ottoman pins: only the slots this plan replaces change; every other Polish/Ottoman slot hash stays the same. Re-record with `PRINT_ART_HASHES=1`.
- Files ≤ ~500 lines; put new painters in new focused files when a style file would pass that.
- `dropHiddenGlows` contract: no hidden window glows (`ottomanGlows.test.ts`, `polishGlows.test.ts`, `allCivsGlows.test.ts`).
- Pins are macOS-specific (canvas hashing); run on this machine.
- Commit messages in English, conventional commits. Do not push; the controller re-dates and pushes.

## Review Focus

1. Silhouette at play zoom (~1.0): each new building must be recognisable as Polish/Ottoman of its age without colour (the M5 silhouette rule) — check rendered shots, not only tests.
2. Construction stages / damage overlays: the new painters must look right in the under-construction rendering the game uses (same path as other painters — check a shot of a foundation stage).
3. Team colour visible on each new building (flag/banner), at noon and dusk.
4. The replaced slots' footprint: nothing drawn outside the building's tiles (vertically within `maxHeight`, horizontally within the canvas) — the civ art tests check the canvas.
5. Other civs unchanged even when a shared kit got a switch: the full art pin suite must pass.
