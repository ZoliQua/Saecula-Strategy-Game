## Design decisions (controller rulings — binding)

1. **Civ registry in TypeScript, not `civs.json`.** `src/config/civs.ts`
   holds `CIV_DEFS: Record<CivId, CivDef>` (availability flag, display key,
   per-age architectural style id, unit look palette/heraldry). Same reason
   as the M3 ruling "stats kept in TypeScript, not JSON": typed, no loader,
   no zod surface. CLAUDE.md §9 M4 and §8.4 are updated to say so (Task 1).
2. **Visual difference only.** No civ bonuses, unique units or unique
   buildings (CLAUDE.md §4.3 "MVP-ben ezek nincsenek"; PROGRAM_TERV "később").
3. **Beyond palette swap.** CLAUDE.md §8.4 recommends palette swap +
   overlay as the minimum; the user's priority on visuals means English gets
   its own *silhouettes* where cheap (roof pitch, gables, chimneys,
   half-timber, towers/spires) on top of palette + overlays. Hungarian output
   must stay pixel-identical after the refactor (hash test).
4. **English per-age character** (CLAUDE.md §4.2 "Tudor, szürke kő, meredek
   tetők"):
   - Age 1 (Roman era): Romano-British — grey rubble stone, timber,
     *steep* thatch / slate, round-ish Celtic accents; cooler, greyer than
     the Hungarian warm terracotta Roman set.
   - Age 2 (Middle Ages): Tudor/Norman — black-and-white half-timber over
     grey stone ground floors, very steep red-brown tile roofs, tall brick
     chimney stacks, jettied upper floors, Norman keep-style town centre.
   - Age 3 (Enlightenment): Georgian — red brick, white sash windows and
     stone quoins, slate hipped roofs, pediments, chimney stacks.
   - Wonder: Gothic cathedral (tall spire, flying-buttress hints, rose
     window) — distinct from the Hungarian baroque basilica.
   - Walls/towers: age 1 timber palisade with earth bank; age 2 grey
     ashlar curtain with square crenellations; age 3 brick star-fort bastion.
5. **Units:** same rigs and gear shapes; civ looks change palette, heraldry
   (Hungarian red-white-green / Árpád stripes; English St George cross
   white-red) and a few hat/shield variants (e.g. English kettle → sallet,
   heater shield with cross). Team colour mask stays authoritative for
   ownership readability.
6. **Who is which civ:** the human picks a civ in setup (Magyar / Angol).
   AI civs: a setup option "Ellenfelek népe" = Vegyes (default; seeded mix
   of available civs) / Magyar / Angol. Stored in `GameSetupConfig`.
7. **Texture budget:** only civs present in the match are painted,
   prewarmed or kept. Civ goes into every civ-dependent texture key
   (`~c<civ>` segment). The ≤ 256 MB GPU budget (all-painted case, 128×128,
   6 players, mixed civs) still binds.
8. **Unavailable civs** (the other six) stay "hamarosan" in setup.

## Global Constraints

These bind every task. Reviewers check them.

1. **Stack:** Phaser 3.80 (WebGL), TypeScript strict (`strict`,
   `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), Vite, Vitest,
   Miniplex ECS, Zustand vanilla store. **No new npm dependencies.**
2. **Language:** code, identifiers, comments, commits in English. Every
   player-visible string lives in `src/i18n/hu.ts`.
3. **Architecture:** ECS world = single source of game truth; Phaser
   objects are render proxies; Zustand holds UI state only.
4. **Balance values** in `src/config/balance.ts` / `aiBalance.ts`
   (aiBalance.ts is at ~398 lines — split it before adding to it).
5. **Art is procedural** (`src/iso/art/`), follows the lighting contract
   (`.superpowers/sdd/2026-10-25-m2-gaps-and-m3/lighting-contract.md`, copied
   into this plan's workspace as `lighting-contract.md`): normal maps (half
   size for units/painted buildings), shadow casters, window glows, team
   mask.
6. **Files stay under ~400 lines.** `any` forbidden.
7. **Tests:** pure logic gets Vitest tests. `npm run lint`, `npm test`,
   `npx tsc --noEmit`, `npm run build` pass at the end of every task.
8. **Performance budget:** p95 frame CPU ≤ 16.7 ms on 96×96, 4 players,
   mid-game (measure ms, not FPS — the display caps FPS). GPU texture memory
   ≤ 256 MB worst case (128×128, 6 players, all ages painted, both civs in
   play). Bundle < 2 MB gzip. Load time must not grow by more than ~1 s per
   extra civ in play.
9. **Visual direction:** warm dark glass DOM UI (amber `#f5a857`, Inter +
   Cinzel); living, animated world.
10. **Commits:** conventional commits on `feat/M4-multi-civ`. Do not push;
    the controller pushes.
11. **Visual verification:** `npm run dev` → `http://localhost:5173/`;
    `window.__game` in dev. Graphics tasks are checked in the browser with
    screenshots saved to the plan workspace `shots/task-N/`, not only by
    tests. Compare Hungarian vs English side by side at noon and dusk.

### Task 1: CLAUDE.md update + civ registry + civ plumbing (no visual change)

**Spec:** CLAUDE.md §4.2, §5.1, §9 M4; design decisions 1, 6, 7.

- Update CLAUDE.md first: §9 M4 says the civ registry is `src/config/civs.ts`
  (not `civs.json`), and records design decisions 3–7 briefly; §6 tree lists
  `src/config/civs.ts`. Commit as `docs:`.
- `src/config/civs.ts`: `CivDef` type (`available: boolean`, `architecture:
  Record<AgeId, ArchStyleId>`, `wallStyle: Record<AgeId, WallStyleId>`,
  `unitLook: UnitLookId`, `heraldry` colours). Hungarian and English
  available; the other six `available: false`. `AVAILABLE_CIVS` derives from
  it.
- `GameSetupConfig`: `civ` (human) + `aiCivs: 'mixed' | CivId`; seeded
  assignment of AI civs (`assignCivs(config, rng)` pure, tested: mixed gives
  at least one of each available civ when ≥ 2 AIs, deterministic per seed).
  `createPlayers` takes the assigned list; drop the hard-coded `'english'`.
  `headlessMatch` passes civs.
- A `civOf(playerId)` source for rendering, sibling of `setAgeSource` in
  `RenderSystem`; threaded into `buildingTexture`, the wall texture path,
  unit sprite creation, HUD thumbnails (human civ), and eviction.
- Texture keys gain a civ segment for civ-dependent art: buildings
  (`building_house~a2~cenglish@p3`), wall pieces, unit sheets/masks/shadows,
  wonder stages. Hungarian keeps a stable key scheme too (`~chungarian`).
  Update `ageArtKey`/`teamArtKey`/`wallPieceKey`/`wallPieceKeyAge` regex,
  `releaseStaleBuildingArt`, `releaseUnusedWallPieces`, `TRIMS`. Team
  variants must borrow the normal map/trim of *their own civ's* base.
- Until Tasks 2–5 land, English resolves to the Hungarian painters through
  the registry, so the game looks exactly as today.
- Prewarm (units, walls) and building pre-paint run only for civs in play.
- Tests: key builders/parsers round-trip with civ; eviction keeps/frees per
  civ; `assignCivs`; setup fallback for unavailable civs.
